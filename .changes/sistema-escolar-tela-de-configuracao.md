titulo: Tela para configurar a integração com o sistema escolar
---

A URL e a chave de API da integração com o sistema escolar (usada pelos agentes
"Alunos" e "Interessados" para consultar matrícula, notas, frequência e catálogo
de cursos) agora têm tela própria, em Configurações › Sua empresa › Sistema
escolar. Antes, configurar essa integração exigia inserir os dados direto no
banco.

Quem administra a organização pode cadastrar, ativar/desativar e remover a
integração pela tela; a chave nunca volta a aparecer depois de salva (só os
últimos 4 dígitos). Ao salvar com a integração ativa, o sistema testa a conexão
na hora e avisa se a URL ou a chave estiverem erradas — sem precisar esperar um
aluno perguntar algo. Organizações que já tinham a integração provisionada
direto no banco continuam funcionando sem qualquer ação.
