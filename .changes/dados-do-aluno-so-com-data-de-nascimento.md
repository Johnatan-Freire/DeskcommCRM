titulo: O agente de alunos só informa nota, falta e situação financeira depois de confirmar a data de nascimento
---

Antes, ter o número de WhatsApp cadastrado bastava para o agente acadêmico
informar notas, faltas e a situação financeira do aluno. Agora ele pede a data
de nascimento do aluno, e quem confere é o próprio sistema escolar — a data
cadastrada nunca sai de lá. Cinco datas erradas para o mesmo número em 15
minutos bloqueiam a confirmação e a conversa passa para a equipe. Se a consulta
ao sistema escolar falhar, ou se o sistema ainda não tiver a confirmação, a
conversa também passa para uma pessoa, em vez de o agente seguir sem o dado.
Exige o sistema escolar atualizado com o contrato de confirmação; até lá, o
agente não informa dado acadêmico nenhum.
